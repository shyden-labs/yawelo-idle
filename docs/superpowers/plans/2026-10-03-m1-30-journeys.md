# M1 #30: Journeys and Culture Cards Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give `@wordfarer/core` its Journeys: timed outings from up to three slots that each bring back a culture card drawn from a seeded stream, with repeats, plus the cards' tagged bonuses, the set bonuses, the festival doubling, the phrase packs that join the pick-up pool and the reward a repeat pays.

**Architecture:** State gains its own random streams (`cards` so far, seeded by `initialState(wall, seed)`), the Journey slots, the held cards in collection order and the tutorial flag. A Journey stores its duration, its return time and its card, both fixed when it starts; the return stores nothing, because a Journey has returned once `sim >= returnsAt`, so `integrate` stays a pure clock move and associativity holds with Journeys in flight. `collectJourney` re-anchors first, like every action that can change a rate, then adds a new card to the held cards or pays a repeat. Every bonus is derived from the held cards: `cards` and `sets` are named lines of the rate breakdown (DN6), and `producedBetween` splits each hour bucket at a held festival card's window edges, mapped to the simulated clock through the skew.

**Tech Stack:** Node 24, npm workspaces, TypeScript 6.0, Vitest 4.1, fast-check 4.10, `Num` over break_infinity.js 2.2.0. No new dependency.

**Spec:** `docs/superpowers/specs/2026-10-01-m1-core-simulation-design.md` (§4, §5, §9), with the parent `docs/superpowers/specs/2026-10-01-wordfarer-design.md` (§4.2). Both are amended by this branch's first commit. Story: #30.

## Review Focus

1. **Repeats are the operator's call, and they reverse the parent spec.** On 2026-10-03 the operator chose draws with replacement at any time ("duplicates of cards is ok throughout ... more gacha-style") and a repeat paying Insight plus Understanding. AC3's test checks every draw against an independent `nextInt` over the pool and expects seed 7 to repeat a card before it has seen all four; M3.9 and M3.10 break the draw and are caught.
2. **The return stores nothing.** A fast-check property splits `integrate` anywhere over three Journeys in flight and compares state, slot status and Understanding; the status flips at exactly `returnsAt` (M3.8), and `advance` counts only the returns in the time it credits (M3.15).
3. **A festival edge inside an hour.** The rate must change at the edge's wall-clock millisecond, on a state whose wall clock runs ahead of its simulated one. M2.1 removes the split, M2.11 finds the edge on the wrong clock and M2.12 judges the festival on the wrong clock; each is caught.
4. **A card's bonus counts from collection.** Production up to the collection is paid at the old rate even when the card waited a day uncollected; M3.14 drops the re-anchor and is caught.
5. **Two Journeys out with one card.** The first collected is new and the second is a repeat (M3.11, M3.13).
6. **Floating point in a cut duration.** `86_400_000 × 0.7` is `60_479_999.99999999`, so the duration is rounded to whole ms (M3.6).

## Decisions this plan makes

- **Repeats** (operator, 2026-10-03, asked interactively and recorded on #30): each Journey draws its card uniformly over the current region's cards in course order, with replacement, from the state's `cards` stream. This replaces parent §4.2's "no duplicates until the set is complete"; the parent and the M1 design are amended in this branch's first commit.
- **A repeat's reward** (operator, 2026-10-03: Insight plus Understanding): Insight 1, 2, 3, 5 and 10 for the tutorial, 2 h, 4 h, 8 h and 24 h, and Understanding equal to the rate at collection times a quarter of the duration (7.5 min, 30 min, 1 h, 2 h, 6 h). These are guesses for the pacing bots (#35) to tune; nothing is measured yet.
- **The card is drawn when the Journey starts**, and the return time is fixed then too, so a later stamp upgrade does not move a Journey already out. Two Journeys can carry the same card; whether a card is new is decided at collection.
- **The return stores nothing, and collection credits.** AC6 credits the card at collection, so the return only changes what `journeyStatus` derives; the bonus counts from collection, not from the return.
- **Card bonuses add inside one line.** An Encounter's `cards` line is `1 + Σ bonus` over the held cards sharing one of its tags, each bonus ×2 while its festival is live; its `sets` line is `1 + Σ bonus` over the complete sets, on every Encounter. Each line shows only when it applies, like a Phrasebook's, and both sit after the Phrasebooks and before `stamps`. A set with no cards is never complete.
- **Festivals run on the wall clock.** A window is half open, `[startWallMs, endWallMs)`, and is judged at the moment's wall time, `t + (wall − sim)`. The skew changes only at an anchor, so a held festival card's edge falls at a fixed simulated time, and `producedBetween` splits the bucket there.
- **The pick-up pool** is the current destination's lexicon, then the held cards' phrase packs in course order, put in curriculum order (CEFR, then that order); a pick-up's `n` counts the items of that pool already picked up.
- **The tutorial Journey runs once per game**, recorded in state when it starts; the stamp cut applies to it like any duration. Durations are rounded to whole ms.
- **Refusals are checked in this order.** Starting: `unknownSlot`, `slotLocked` (with the slots open), `slotBusy` (away or returned), `unknownDuration`, `tutorialUsed`, `noCards`. Collecting: `unknownSlot`, `slotEmpty`, `notReturned` (with the return time).
- **A production segment must advance.** `producedBetween` throws a `RangeError` when a segment would end at or before its start, instead of looping forever. Correct code never reaches it; M2.11, which finds an edge on the wrong clock, does, and the guard turns what was an hour-long hang into a named failure.
- **The current region is the course's first** until Set Sail (#31) moves it on, exactly as `currentDestination` does for words.

  held: readonly CultureCard[],
  encounter: Encounter,
  wall: number,

  course: CourseData,
  held: readonly CultureCard[],

  let factor: number | undefined;
  for (const region of course.regions) {
    for (const set of region.cardSets) {
      const cards = region.cultureCards.filter((c) => c.setId === set.id);
      if (cards.length > 0 && cards.every((c) => ids.has(c.id))) {
        factor = (factor ?? 1) + set.bonus;
      }
    }
  }

 * there, so the rate changes exactly at the edge (design §5).

export function nextFestivalEdge(
  held: readonly CultureCard[],
  wall: number,
): number | undefined {
  let next: number | undefined;

    for (const w of card.festival?.windows ?? []) {
      for (const edge of [w.startWallMs, w.endWallMs]) {

      }

/**
 * Journeys (parent spec §4.2, M1 design §5, #30): timed outings that bring
 * back a culture card.
 *
 * A Journey's card is drawn when it starts, uniformly over the current
 * region's cards in course order from the state's `cards` stream, with
 * replacement, so a held card can come again (operator, 2026-10-03). Its
 * return time is fixed then too. A return changes no stored quantity: the
 * Journey has returned once `sim >= returnsAt`, so the return falls at the
 * same simulated time however `integrate` is split. Collecting credits the
 * card at that moment: a card not yet held joins the held cards, and a held
 * one pays the repeat reward instead.
 */
import {
  BALANCE,
  JOURNEY_DURATION_IDS,
  type JourneyDurationId,
} from './balance';
import { simMs } from './clock';
import type { CourseData, CultureCard } from './course';
import { Num } from './num';
import { rateAt } from './production';
import { intFrom } from './rng';
import { reanchor, type Rejection, type Result } from './sim';
import type { GameState, Journey } from './state';
import { journeyDurationFactor, journeySlots } from './upgrades';

/** What a slot holds: `locked` until bought, then `empty`, `away` or `returned`. */
export type JourneyStatus = 'locked' | 'empty' | 'away' | 'returned';

/**
 * The cards Journeys draw from: the current region's, in course order. The
 * current region is the course's first until Set Sail (#31) moves it on.
 */
export function cardPool(course: CourseData): readonly CultureCard[] {
  return course.regions[0]?.cultureCards ?? [];
}

function durationIndex(durationId: string): number {
  return JOURNEY_DURATION_IDS.findIndex((id) => id === durationId);
}

function table(values: readonly number[], index: number): number {
  const value = values[index];
  if (value === undefined) {
    throw new RangeError(`no journey table entry ${String(index)}`);
  }
  return value;
}

/** How long a Journey of `durationId` takes when started from `state`, in whole ms. */
export function journeyDurationMs(
  state: GameState,
  durationId: JourneyDurationId,
): number {
  const listed = table(BALANCE.journeys.durationsMs, durationIndex(durationId));
  return Math.round(listed * journeyDurationFactor(state));
}

function slotRejection(slot: number): Rejection | undefined {
  return Number.isSafeInteger(slot) &&
    slot >= 0 &&
    slot < BALANCE.journeys.maxSlots
    ? undefined
    : { kind: 'unknownSlot', slot };
}

function journeyIn(state: GameState, slot: number): Journey | null {
  return state.journeys[slot] ?? null;
}

/** What slot `slot` holds at the state's simulated time. */
export function journeyStatus(state: GameState, slot: number): JourneyStatus {
  const refused = slotRejection(slot);
  if (refused !== undefined) {
    throw new RangeError(`no journey slot ${String(slot)}`);
  }
  if (slot >= journeySlots(state)) return 'locked';
  const journey = journeyIn(state, slot);
  if (journey === null) return 'empty';
  return state.sim < journey.returnsAt ? 'away' : 'returned';
}

function withSlot(
  state: GameState,
  slot: number,
  journey: Journey | null,
): readonly (Journey | null)[] {
  return state.journeys.map((j, i) => (i === slot ? journey : j));
}

/**
 * Send a Journey of `durationId` out from slot `slot` at the state's
 * simulated time. Refused, in this order, when the slot does not exist, is
 * not yet bought or already holds a Journey (returned or not), the duration
 * is unknown or is the tutorial a second time, or the region has no cards.
 */
export function startJourney(
  course: CourseData,
  state: GameState,
  slot: number,
  durationId: string,
): Result {
  const refused = slotRejection(slot);
  if (refused !== undefined) return { ok: false, rejection: refused };
  const open = journeySlots(state);
  if (slot >= open) {
    return { ok: false, rejection: { kind: 'slotLocked', slot, open } };
  }
  if (journeyIn(state, slot) !== null) {
    return { ok: false, rejection: { kind: 'slotBusy', slot } };
  }
  const id = JOURNEY_DURATION_IDS.find((d) => d === durationId);
  if (id === undefined) {
    return { ok: false, rejection: { kind: 'unknownDuration', durationId } };
  }
  if (id === 'tutorial' && state.tutorialJourneyUsed) {
    return { ok: false, rejection: { kind: 'tutorialUsed' } };
  }
  const pool = cardPool(course);
  if (pool.length === 0) {
    return { ok: false, rejection: { kind: 'noCards' } };
  }
  const draw = intFrom(state.rng, 'cards', pool.length);
  const card = pool[draw.value];
  if (card === undefined) {
    throw new RangeError(
      `drew card ${String(draw.value)} of ${String(pool.length)}`,
    );
  }
  const journey: Journey = {
    durationId: id,
    returnsAt: simMs(state.sim + journeyDurationMs(state, id)),
    cardId: card.id,
  };
  return {
    ok: true,
    state: {
      ...state,
      rng: draw.streams,
      journeys: withSlot(state, slot, journey),
      tutorialJourneyUsed: state.tutorialJourneyUsed || id === 'tutorial',
    },
  };
}

/**
 * Collect the Journey in slot `slot` at the state's simulated time. Refused
 * when the slot does not exist or is empty, or the Journey has not returned.
 * A card not yet held joins the held cards, so its bonus and phrase pack
 * count from now on. A held card pays the repeat reward instead: Insight by
 * duration, and Understanding equal to the rate now times that duration's
 * reward time. Either way production up to now is banked first.
 */
export function collectJourney(
  course: CourseData,
  state: GameState,
  slot: number,
): Result {
  const refused = slotRejection(slot);
  if (refused !== undefined) return { ok: false, rejection: refused };
  const journey = journeyIn(state, slot);
  if (journey === null) {
    return { ok: false, rejection: { kind: 'slotEmpty', slot } };
  }
  if (state.sim < journey.returnsAt) {
    return {
      ok: false,
      rejection: { kind: 'notReturned', slot, returnsAt: journey.returnsAt },
    };
  }
  const anchored = reanchor(course, state);
  const emptied = { ...anchored, journeys: withSlot(anchored, slot, null) };
  if (!anchored.cards.includes(journey.cardId)) {
    return {
      ok: true,
      state: { ...emptied, cards: [...anchored.cards, journey.cardId] },
    };
  }
  const index = durationIndex(journey.durationId);
  const { duplicateInsight, duplicateUnderstandingMs } = BALANCE.journeys;
  const understanding = Num.add(
    Num.fromTuple(anchored.anchor.understanding),
    Num.div(
      Num.mul(
        rateAt(course, anchored, anchored.sim),
        Num.from(table(duplicateUnderstandingMs, index)),
      ),
      Num.from(1000),
    ),
  );
  const insight = Num.add(
    Num.fromTuple(anchored.insight),
    Num.from(table(duplicateInsight, index)),
  );
  return {
    ok: true,
    state: {
      ...emptied,
      anchor: { ...emptied.anchor, understanding: Num.toTuple(understanding) },
      insight: Num.toTuple(insight),
    },
  };
}
