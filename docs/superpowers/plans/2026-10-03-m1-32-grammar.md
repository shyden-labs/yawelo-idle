# M1 #32: Grammar Nodes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give `@wordfarer/core` grammar nodes (parent §4.3): bought with Insight from region 2, each one multiplies the bonus of every held word on its roots by `1 + g` and teaches its derived words, its effect shows as a named `grammar` line of the rate breakdown (DN6), and a sail keeps it.

**Architecture:** State gains `grammar`, the owned node ids in the order bought. A new leaf module, `grammar.ts`, prices the next node, finds a node and its region, lists the owned nodes in course order and gives each covered root its factor. It imports nothing from `sim.ts`. `buyGrammarNode` is an action, so it sits in `sim.ts` beside `buyUpgrade`. `production.ts` carries each held word's grammar factor beside its bonus and adds a `grammar` line after `words`: the multiplied M_words over the plain one, so `words × grammar` is what is paid. `pickUpPool` takes the owned nodes and puts their derived words after the card packs, and `lexiconItem` knows them. `sailPreview` counts the nodes a sail keeps.

**Tech Stack:** Node 24, npm workspaces, TypeScript 6.0, Vitest 4.1, `Num` over break_infinity.js 2.2.0. No new dependency.

**Spec:** `docs/superpowers/specs/2026-10-01-m1-core-simulation-design.md` (§4, §5, §9), with the parent `docs/superpowers/specs/2026-10-01-wordfarer-design.md` (§4.3). The M1 design is amended by this branch's first commit. Story: #32.

## Review Focus

1. **The breakdown line is a ratio.** Grammar multiplies terms inside the sum `M_words = 1 + Σ b_w`, so no single factor of the product names it unless one is derived. The `words` line stays the plain sum (M3.5), and the `grammar` line is `(1 + Σ b_w·f_w) / (1 + Σ b_w)`, so the rate, the product of its lines, is what grammar pays (AC2's "pays the multiplied rate"). The line shows only when a word on the Encounter's tags has a factor (M3.7).
2. **Only those words.** A word with no root, or a root no owned node covers, keeps its bonus (M3.3, M3.4), and a covered word counts only on its own tags (M3.6).
3. **Nodes on one root compound.** `ber-` and `me-` both attach to `ajar`, so `ajar` gets `1.5 × 1.5` (M3.2). AC2 says each node multiplies; compounding is that reading taken literally.
4. **The pool never depends on purchase order.** Derived words join in the course order of the owned nodes, after the card packs, before the CEFR sort (M4.2, M4.3).
5. **A sail keeps grammar.** #31's AC3 test reads every state key; its states now own nodes, so the keeps-everything-else check compares a non-empty `grammar` (M5.1).
6. **An import cycle shipped through every gate step.** This branch's first build put `buyGrammarNode` in `grammar.ts`, importing `reanchor` from `sim.ts`, which made four value-import cycles. A probe over `packages/core/src` found them (20 modules, 99 relative imports, all read); the stages were rebuilt with the action in `sim.ts`, and the same probe finds none (97 imports). #92 turns the probe into a guard.

## Decisions this plan makes

- **Availability:** grammar opens once `BALANCE.grammar.opensAtRegion` (2) regions are reached, and a node is available once its own region is reached, as Encounters are (#31). Region 1's nodes are bought from region 2 on.
- **Cost** (a starting value for #35's bots to tune): the next node costs `50 · 1.5^n` Insight, `n` being the nodes already owned, so the player chooses the order.
- **Refusals are checked in this order:** `unknownGrammarNode`, `grammarNodeOwned`, `grammarNodeLocked` (naming the node's region and the regions reached), `grammarNodeUnaffordable` (naming the cost and the Insight held). A purchase banks production up to it first.
- **Factor:** a word's grammar factor is `(1 + g)^k` by repeated multiplication, `k` being the owned nodes on its root; a word with no root has factor 1. An owned node the course does not have is refused by name.
- **Pool:** the current destination's lexicon, then the held cards' packs, then the owned nodes' derived words in course order, sorted stably by CEFR.

import { BALANCE } from './balance';
import type { CourseData, GrammarNode } from './course';
import { Num } from './num';
import type { GameState } from './state';

const COST_C0 = Num.from(BALANCE.grammar.costC0);
const COST_GROWTH = Num.from(BALANCE.grammar.costGrowth);

/** The Insight cost of the next node when `owned` nodes are owned. */
export function grammarNodeCost(owned: number): Num {
  if (!Number.isSafeInteger(owned) || owned < 0) {
    throw new RangeError(
      `owned must be a safe non-negative integer, got ${String(owned)}`,
    );
  }
  return Num.mul(COST_C0, Num.pow(COST_GROWTH, owned));
}

 * since every factor is the same number.
 */

  course: CourseData,
  state: GameState,
